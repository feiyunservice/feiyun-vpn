Feiyun Privacy Policy

Last updated: July 6, 2026

Thank you for using Feiyun. This policy briefly explains how we handle your information.

1. Information We Collect

Feiyun can be used without registering an account. We only automatically collect the following anonymous information:

  • Device hardware ID, device model, system version, and operating system platform

None of the above data contains any information that can identify you personally.

2. Information We Never Collect (No-Logs Commitment)

We solemnly commit to never logging the following information:

  • Websites you visit or IP addresses you access
  • Any content of your transmitted traffic
  • Your DNS query records
  • Your real IP address
  • Your connection timestamps or session durations

Even if legally required, we cannot provide data we have never possessed.

3. How We Use Information

We use the collected information only for:

  • Fixing app errors and improving connection quality
  • Maintaining service stability
  • Identifying device uniqueness

We never sell any user data.

4. Information Sharing

We do not share user data with any third party. We disclose only the minimum necessary information when explicitly required by law.

5. Data Security

  • AES-256 encryption protects data in transit
  • Anonymous diagnostic data is periodically purged
  • Internal access to data is strictly restricted

6. Contact Us

If you have any questions about this policy, please contact us:

Email: privacy@feiyun.app
Website: https://feiyun.app

If there are any material changes to this policy, we will announce them on our website in advance. Continued use of the service constitutes acceptance of the updated policy.
